# Krynet for iOS

> **Unofficial community client**

Krynet for iOS is an independent community-maintained C++ client for Krynet.

This project is part of **Krynet Community Ports**.

It is **not affiliated with, endorsed by, maintained by, reviewed by, or used by Krynet, LLC or the Krynet Team.**
