## 🧩 What This Project Is

Krynet Community Ports is a place for community-built software around Krynet.

Projects here may include:

* Community ports
* Alternative clients and interfaces
* Integrations
* Browser extensions and userscripts
* Experimental features
* Compatibility layers
* Developer tooling
* Other community projects related to the Krynet ecosystem

These projects are developed independently and may differ significantly from official Krynet software.

## 📦 Installation

Installation instructions are provided separately for each project.

Before installing anything, check the project's README for:

* Supported platforms
* Required dependencies
* Configuration
* Known limitations
* Security considerations

Only install software you understand and trust.
